Connection

Provider, endpoint and credentials.

FluentText talks to any service that offers OpenAI-compatible chat completions. Pick Groq for the default, or use another provider, a local model server, a custom endpoint, or a Cloudflare Worker you run yourself. Keys and proxy tokens are stored only in this browser profile and are sent only to the endpoint you choose.

Base URL of the API. /chat/completions is added automatically when it is missing. Web addresses must match the provider's documented base URL; a local server works too. For a Worker that takes one fixed URL, choose Cloudflare Worker / proxy above instead.

Choose how the key should be sent.

Requests go to this exact address, so a Worker can check it as-is. No API key is stored in the browser: the Worker adds the real key. It must accept POST requests with CORS headers.

Sent as Authorization: Bearer and stored only in this browser. Leave it empty if your Worker has no token.

Models

Choose what runs while you type and on demand.

Model names are provider-specific. Use "Load models" after saving to see what your account can use right now. Some servers do not publish a model list; in that case type a name from the provider's documentation.

Translation

Pinned languages and the tone used.

Select text, then use the star or right-click > FluentText > Translate to. The source language is detected automatically. Pinned languages are listed first. Any other language is one step away: the star menu has an "Other language..." box that accepts anything you type, and the right-click menu has a "More languages" list.

Quick actions and shortcuts

What the two quick shortcuts do, and their keys.

Two shortcuts apply a change straight to the selected text, without opening the menu. Choose what each one does here. The key combinations themselves belong to the browser: use the button below to change them.

Shortcut page: chrome://extensions/shortcuts

Privacy

Where your text and credentials go.

Text in a box that FluentText is watching is sent to your chosen provider (Groq by default) or to the Worker or proxy you configure, so it can be checked. Password fields, email fields, code editors, and fields with spellcheck turned off are skipped. Nothing is sent to the developer or anyone else. Your key, proxy URL and token, settings and dictionary stay in this browser; only settings sync through your browser account, and keys and proxy details never do. Turn the extension off on any site from the toolbar popup.
