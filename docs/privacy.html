FluentText: Privacy Policy

Last updated: October 31, 2026

FluentText is an open-source browser extension (GPL v3). This page explains what happens to your data. The short version: your text goes to the AI provider, or to the proxy, that you choose so it can be checked, and nowhere else.

What the extension sends

When you type in a text box that FluentText is watching, or when you select text and choose Rewrite, Translate or Detect language, the extension sends that text to the service configured in its settings:

  • Groq (api.groq.com) using the Groq API key you provide, by default,
  • Another OpenAI-compatible endpoint you enter, such as OpenAI, OpenRouter, Mistral, or a local Ollama server, or
  • A Cloudflare Worker or other proxy you run, at the Worker URL you enter. The proxy forwards the text to its own AI provider.

The text is used only to return suggestions, rewrites, translations or a language name. The extension does not send text from password fields, email fields, code editors, or fields with spellcheck turned off. How the provider or proxy handles your text is governed by that provider's privacy policy and terms. If you use a proxy, its operator (you) is responsible for how it is run.

Authentication information

The API key or proxy token you enter is stored only in your browser's local extension storage on this device. It is sent only to the endpoint it belongs to: an API key in the authentication header you selected, or a proxy token as Authorization: Bearer to your Worker. The real AI provider key stays inside the Worker and is never sent to the browser. FluentText does not sync keys or proxy tokens between devices and never sends them to the developer. Removing them in settings or uninstalling the extension deletes them.

What is stored, and where

  • API keys, proxy URL and proxy token: in your browser's local extension storage on this device. They are not synced to other devices.
  • Settings (including the chosen provider, custom endpoint, model names, languages and quick actions): in your browser's extension storage, which your browser may sync through your own browser account. Settings contain no key, proxy URL or proxy token.
  • Personal dictionary and disabled sites: in local extension storage on this device, because they can grow too large for synchronized storage.
  • Check results: held in memory while a page is open to avoid repeat requests, and discarded when the page closes.

What we do not do

  • No analytics, telemetry, advertising or tracking.
  • No servers operated by the developer receive your text, keys, proxy details or settings.
  • No selling or sharing of data.
  • No remote code is loaded.

Permissions

The extension runs on web pages so it can find text boxes and show suggestions. It needs storage to remember settings and contextMenus for the right-click menu. It has access to api.groq.com for the default provider. When you add a different endpoint or a Worker URL, the browser asks for access to that host; that permission is optional and can be revoked in the browser's extension settings.

Your control

Turn the extension off globally or for a single site from the toolbar popup, change or remove your key, endpoint, Worker URL or proxy token in settings, or uninstall the extension to delete everything it stored. Revoking a host permission stops requests to that endpoint immediately.

Bug reports

The "Report a bug" link opens your own email client with a prefilled message containing the extension version and browser name. Nothing is sent unless you send the email. Please do not include API keys, proxy tokens or private text in a bug report.
